FAQ

Questions players ask

Which games does PeakPC speed up?

All of them. PeakPC tunes Windows itself, so every PC game gets the benefit. Popular games like Valorant, CS2, Fortnite, Warzone and Apex can also get High CPU priority in one click, and GameLoop players get extra emulator and PUBG Mobile tools.

Does PeakPC add DLSS 5?

No. DLSS 5 is NVIDIA technology that needs a GeForce RTX 50-series card and a game that supports it, so no app can add it. What PeakPC 1.8 does have is Upscaler swap: in games that already offer DLSS, FSR or XeSS, it installs the free OptiScaler so you can use a different upscaler, extra sharpening or frame generation. Emulators get full-screen FSR upscaling with Magpie.

Is Upscaler swap safe?

Use it in single-player and offline games only, because anti-cheat in online games can ban you for added files. PeakPC refuses known online games, keeps every file it replaces, and Uninstall puts the game back exactly as it was.

Is PeakPC really free?

Yes. The Free version opens without a key and never expires. It includes the safe tweaks, DNS, the 0.5 ms timer, three power plans, the app installer, startup manager, cleanup and restore. Pro unlocks the rest.

Windows says "Windows protected your PC". Is it safe?

PeakPC is new and not code-signed yet, so Microsoft SmartScreen warns about it like it does for most new apps. Choose More info, then Run anyway. Only download PeakPC from this page or from our Discord.

Can I undo what PeakPC changes?

Yes. Every tweak saves the original value before it changes anything. Press Undo on a single tweak, or use Restore to undo everything. PeakPC can also make a Windows restore point first.

Can it get my game account banned?

PeakPC doesn't inject anything into games or GameLoop. GameLoop tweaks change GameLoop's own settings, and the PUBG editor only sets graphics values in Active.sav, which you copy in yourself. Each game publisher sets its own rules, so use any third-party tool with that in mind.

Why is 120 FPS the maximum for PUBG Mobile?

120 FPS (Ultra Extreme) is the highest frame rate PUBG Mobile offers. 165 or 240 FPS don't exist in the game, whatever your screen supports.

How do I buy Pro?

Join our Discord, pick 1 Month or Lifetime and pay. You'll get a key: open Upgrade to Pro in PeakPC, paste it and press Activate Pro. Include your Machine ID, shown in PeakPC, when you buy.

I reinstalled Windows. Do I need a new key?

No. Send your new Machine ID on Discord and we'll move your key to it.

How do updates work?

PeakPC checks for a new version every time it opens, downloads it and restarts by itself. The bell in the top-right corner shows what changed.
